## Aim
To develop a Flutter application that tracks water consumption using Add Glass and Reset buttons, demonstrating StatefulWidget and setState().

## Description
The Water Usage Counter is a simple Flutter application that counts the number of glasses of water consumed and calculates the approximate total volume in liters.

## Features
- Add Glass: Increases the glass count by one.
- Reset: Resets the counter to zero.
- Water calculation: Assumes each glass contains 250 ml (0.25 liters).
- Dynamic UI: Updates the count and total liters using setState().
- SDG awareness: Displays a message related to SDG 6.

## Technologies Used
- Flutter
- Dart
- Material Design widgets

## Flutter Concepts
- StatefulWidget
- setState()
- Scaffold and AppBar
- Column, Container, and Text
- ElevatedButton and OutlinedButton

## SDG 6 – Clean Water and Sanitation
The application promotes awareness of water consumption by tracking the volume of water consumed. It encourages users to understand their water usage and supports responsible water management.
